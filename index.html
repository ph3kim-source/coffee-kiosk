주문하기와 관리자 화면은 최종 coffee_kiosk.py를 자바스크립트로 한 줄씩 옮긴 엔진 위에서 돌아갑니다. 화면의 버튼은 원래 프로그램에 번호와 금액을 입력하는 것과 같고, 안내 문구도 프로그램 출력 그대로입니다.

주문하기 관리자 페이지 18단계 과정

01과제

과제가 요구한 것

7차시 과제는 300원짜리 커피 한 잔을 파는 기본 조건에서 시작해, "수정하기 1~8"을 거치며 기능을 하나씩 늘려 가는 것이었습니다. 수정하기 6은 조건이 두 부분으로 나뉘어 있어 조건 카드는 모두 열 장입니다. 카드마다 그 조건을 처음 구현한 단계를 적었습니다.

02개발 과정

18단계로 자란 키오스크

10월 13일부터 23일까지 18단계로 나눠 진행했습니다. 단계마다 요청 → 코드 → 실행 테스트 → 다음 단계 순서를 지켰고, 단계 색은 원두를 볶는 정도처럼 갈수록 진해집니다.

단계 기록

단계를 펼치면 바뀐 내용과 실행해 본 테스트가 나옵니다.

코드 변천

막대는 단계별 실행 코드 줄 수(빈 줄·주석·문서 문자열 제외)입니다. 13·14·15·17단계는 보고서에 코드가 실려 있지 않아 비워 두었습니다. 막대나 단계 번호를 누르면 그 단계의 코드가 나오고, 바로 앞 단계와 달라진 줄이 칠해집니다.

03문제 해결

찾아낸 문제와 고친 단계

과제 조건을 모두 구현한 뒤, 코드에 남은 문제를 두 번에 걸쳐 유형별로 찾아내고 심각한 것부터 고쳤습니다. 순서는 "틀린 결과가 나오는가 → 사용자가 불편한가 → 조건 밖의 기능인가 → 보기에만 영향이 있는가"였습니다.

04협업과 피드백

세 사람의 코드, 열두 개의 피드백

세 사람이 각자 다른 방향으로 만든 키오스크에서 장점을 골라 하나로 합쳤고(17단계), 최종 피드백 12개를 반영해 완성했습니다(18단계). 받아들이지 않은 것도 이유와 함께 남겼습니다.

팀원 코드 합치기

줄 수는 각자의 진행 코드 기준입니다. 도현의 코드는 16단계까지 진행된 상태로 최종본의 뼈대가 됐습니다.

최종 피드백 12개

회색 칸은 반영 전, 진한 칸은 반영 후 실제 출력 문구입니다.

05최종 구조

coffee_kiosk.py 들여다보기

최종 코드는 설정 값과 여덟 구역의 함수로 나뉩니다. 함수 이름을 누르면 그 함수가 부르는 함수와 그 함수를 부르는 곳이 표시되고, 아래에서 실제 코드를 볼 수 있습니다.

함수 지도

구역은 코드 안의 # ---------- 재고 ---------- 같은 표시를 그대로 따랐습니다.

설정 값

코드 맨 위의 값만 바꾸면 재고, 쿠폰 기준, 옵션, 처음 현금이 바뀝니다.

자료구조와 저장 파일

메모리의 자료구조 네 개 중 세 개가 두 파일에 저장돼, 프로그램을 껐다 켜도 이어집니다.

06주문 흐름

손님 한 명이 지나가는 길

main()의 반복문 한 바퀴가 손님 한 명입니다. 상자 아래 글자는 그 일을 맡은 함수이고, 상자를 누르면 함수 지도에서 그 함수가 열립니다. 주문하기 화면도 이 순서 그대로 움직입니다.

07핵심 알고리즘

직접 바꿔 보는 알고리즘 다섯 가지

값을 바꾸면 최종 코드와 같은 규칙으로 결과가 바로 계산됩니다. 카드마다 그 규칙이 들어 있는 실제 코드 줄을 함께 붙였습니다.

08주문 데이터

팀이 테스트하며 쌓은 주문 기록

최종 폴더의 주문기록.csv와 키오스크상태.json을 그대로 읽어 정리했습니다. 테스트 중에 쌓인 기록이라 실제 매출이 아니라 프로그램이 데이터를 어떻게 남기는지 보여 주는 자료입니다. 주문하기 화면은 이 파일들로 시작합니다.
