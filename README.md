# 커피 키오스크 시각화

계산프로그래밍2 중간고사 프로젝트(Team2)에서 만든 커피 키오스크 프로그램 `coffee_kiosk.py`를 브라우저에서 직접 써 볼 수 있게 만든 페이지입니다.

**바로 열기: https://ph3kim-source.github.io/coffee-kiosk/**

- **주문하기**: 메뉴 → 잔 수·옵션 → 장바구니 → 쿠폰 → 현금·카드 결제까지 키오스크 화면으로 주문
- **관리자**: 비밀번호 `0000` → 품절 리필, 누적 판매, 현금 관리, 메뉴·가격·재고 변경, 영업 종료
- **프로그램 내부**: 화면 버튼이 원래 프로그램에 넣는 입력과 프로그램이 출력한 글자를 콘솔로 확인. 저장 파일 탭에서 `주문기록.csv`를 내려받으면 엑셀로 바로 열 수 있음
- **프로젝트 기록**: 과제, 개발 과정, 문제 해결, 협업과 피드백, 최종 구조, 주문 흐름, 핵심 알고리즘, 주문 데이터, 정리, 그리고 **최종 코드**(`coffee_kiosk.py` 전체를 목차와 함께 보고 내려받기)

화면 뒤에서는 `coffee_kiosk.py`를 자바스크립트로 옮긴 엔진이 돌아갑니다. 같은 입력 25가지를 원본 파이썬과 이 엔진에 넣어 화면 출력과 저장 파일이 글자 하나까지 같은지 확인했습니다.

페이지는 `index.html` 한 파일입니다. 내려받아 더블클릭해도 열립니다.
